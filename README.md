# Daily Charm 홍보 이미지

데일리 참(Daily Charm) 홍보 글에 붙는 그림이에요. 앱의 Threads·블루스카이 자동 게시가 이 저장소의 파일을 그대로 가져가 씁니다. Threads는 공개된 주소의 사진만 가져갈 수 있어서 이 저장소는 공개로 둡니다.

| 폴더 | 내용 |
| --- | --- |
| `zh-Hant/` | 대만용 번체 중국어 카드 (1080 × 1350, 4:5, JPEG) |

| 파일 | 카드 |
| --- | --- |
| `brand.jpg` | 記住與實踐，為了你的每一天 — 언덕 위의 小精靈과 발자국 |
| `charms.jpg` | 越記錄，越能遇見新的小精靈 — 선반 위의 小精靈 15마리 |
| `footprints.jpg` | 完成一件待辦，就留下一個足跡 — 발자국과 작은 방 |
| `focus.jpg` | 和小精靈一起，專心一下 — 밤의 방, 番茄鐘 |
| `rest.jpg` | 錯過一天，也沒關係 — 쿠션 위에서 자는 小精靈 |
| `diary.jpg` | 今天，用一句話記下來 — 한 줄 일기와 책상 |
| `typing.jpg` | 打一行字，時間就排好了 — 제목에 날짜·시간 쓰기 (1.0.2 기능) |

그림은 앱 저장소의 `tools/promo/make.js`로 다시 만들 수 있어요. 파일 이름을 바꾸면 홍보 글 설정(`tools/autopost/posts.json`)의 `photos`도 함께 바꿔야 해요.
