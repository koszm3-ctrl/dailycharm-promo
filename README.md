# Daily Charm 홍보 이미지

데일리 참(Daily Charm) 홍보 글에 붙는 그림이에요. 앱의 Threads·블루스카이 자동 게시가 이 저장소의 파일을 그대로 가져가 씁니다. Threads는 공개된 주소의 사진만 가져갈 수 있어서 이 저장소는 공개로 둡니다.

| 폴더 | 내용 |
| --- | --- |
| `zh-Hant/` | 대만용 번체 중국어 카드 (1080 × 1350, 4:5, JPEG) |
| `ja/` | 일본용 일본어 카드 (같은 크기, 같은 그림) |

| 파일 | 대만 (`zh-Hant/`) | 일본 (`ja/`) | 그림 |
| --- | --- | --- | --- |
| `brand.jpg` | 記住與實踐，為了你的每一天 | 覚えて、やってみる。あなたの毎日のために | 언덕 위의 참들과 발자국 |
| `charms.jpg` | 越記錄，越能遇見新的小精靈 | 記録するほど、チャームに出会える | 선반 위의 참 15마리 |
| `footprints.jpg` | 完成一件待辦，就留下一個足跡 | やることを終えたら、あしあとがひとつ | 발자국과 작은 방 |
| `focus.jpg` | 和小精靈一起，專心一下 | チャームと一緒に、ちょっと集中 | 밤의 방, 집중 타이머 |
| `rest.jpg` | 錯過一天，也沒關係 | 一日休んでも、だいじょうぶ | 쿠션 위에서 자는 참 |
| `diary.jpg` | 今天，用一句話記下來 | 今日のことを、一行で残そう | 한 줄 일기와 책상 |
| `typing.jpg` | 打一行字，時間就排好了 | 一行書くだけで、時間が決まる | 제목에 날짜·시간 쓰기 (1.0.2 기능) |

그림은 앱 저장소의 `tools/promo/make.js`로 다시 만들 수 있어요(`node tools/promo/make.js ja ../dailycharm-promo/ja`). 파일 이름을 바꾸면 홍보 글 설정(`tools/autopost/posts/` 안의 나라별 파일)의 `photos`도 함께 바꿔야 해요.

Promotion images for the Daily Charm app's posts on Threads and Bluesky, made from the app's own art.
