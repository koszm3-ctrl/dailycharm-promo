# 인스타그램 발행 대기열

검수를 통과한 데일리 참 인스타그램 카드뉴스가 여기서 차례를 기다려요. 앱 저장소의 자동 게시(`tools/cardnews/instagram.mjs`, 홍보 글 자동 게시 워크플로의 `instagram` 작업)가 **매일 한국 시간 저녁 8시 45분**에, 아직 올리지 않은 것 중 폴더 이름이 가장 앞선 카드뉴스를 하나 올려요. 인스타그램은 공개된 주소의 사진만 가져갈 수 있어서 이 저장소에 둬요.

| 파일 | 내용 |
| --- | --- |
| `<번호>-<이름>/01.jpg …` | 올릴 사진 (1080 × 1350, 4:5, JPEG). 01부터 차례로 한 게시물이 돼요 |
| `<번호>-<이름>/post.json` | 표지 제목(`title`), 캡션과 해시태그(`caption`), 사진마다 대체 텍스트(`alts`), 장 수(`slides`), 기다리는 앱 버전(`since`) |

- 앱 저장소의 `node tools/cardnews/outbox.mjs Marketing/Instagram/posts/<폴더>`가 이 폴더를 만들어요. 검수를 통과한 카드뉴스만 들어오고, 기획안·검수 기록은 들어오지 않아요.
- `since`가 있으면 그 버전이 App Store에 나온 뒤에 올라가요.
- 이미 올라간 카드뉴스는 다시 올리지 않아요. 인스타그램 계정의 최근 게시물에서 캡션 첫 줄이 같은 것을 찾아요. 그래서 올린 뒤 인스타그램에서 캡션 첫 줄은 고치지 않아요.
- 올리지 않으려면 그 폴더를 지우면 돼요.
